# Högskolan på Åland — AI Chatbot Widget v3

## What it does
A RAG-powered chatbot that answers questions about programmes and admissions at [ha.ax](https://www.ha.ax/), based on the university's own website content.

> This repository is the third iteration of the ha.ax chatbot, focused on answer accuracy and evaluated against feedback from university staff. Earlier versions:
> - **v1:** [ha.ax-chatbot-demo](https://github.com/zinebnadak/ha.ax-chatbot-demo): the original demo
> - **v2:** [ha.ax-chatbot](https://github.com/zinebnadak/ha.ax-chatbot): embeddable widget with hybrid retrieval, guardrails, rate limiting and observability
